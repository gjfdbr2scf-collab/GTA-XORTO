# Peine PSP Game – Game Design

## Platform

* PlayStation Portable (PSP)
* Visual target: besser als Nintendo 64, angepasst an die PSP-Hardware
* Steuerung: N64-artige Joystick-Steuerung
* Kein Online-Modus
* Keine Server

## Main Menu

Das Hauptmenü enthält genau diese vier Optionen:

1. Story Mode
2. Free Open World
3. Multiplayer
4. System Settings

## Intro

Das Spiel beginnt mit einem Young-Lean-Konzert.

* Die Musik läuft ungefähr 5–6 Sekunden.
* Danach wird das Bild langsam dunkler.
* Die Musik blendet aus.
* Danach wählt der Spieler seinen Namen.
* Danach wählt der Spieler seine Sprache.
* Kurmanji ist als Sprache enthalten.
* Name und Sprache werden auf der SD-Karte gespeichert.

## Story Mode

### 1. Brücke

Der Spieler steuert Setzmann.

Es gibt eine Erinnerung an „Ginseng Strip 2002“.

### 2. Young Lean

Ein Mann mit Kapuze erscheint, summt „Ginseng Strip 2002“ und wird als Young Lean erkannt.

Der Dialog ist auf Englisch.

### 3. Spielplatz

Der Spieler kann:

* sitzen
* chillen
* ein Lied singen
* den nächsten Tag planen

### 4. Zuhause

Es gibt:

* Betten/Matratzen
* eine PS5
* ein Gespräch über den nächsten Tag

Der ältere Cousin schlägt Fußball um 2 Uhr nachts vor.

Danach wird Fußball geschaut.

### 5. Nacht

Ein schwarzer Fade erscheint.

Danach schlafen die Charaktere und der nächste Morgen beginnt.

### 6. Zweites Treffen

Das nächste Treffen findet wieder an der Brücke statt.

Setzmann wird gesteuert.

### 7. Aldi

Der Aldi-Abschnitt ist spielbar.

Die Gruppe kauft:

* Getränke
* Center Shocks

Die Getränkedesigns sind eigenständig.

### 8. Zurück zum Spielplatz

Young Lean sagt, dass es wahrscheinlich das letzte Treffen ist, weil er zurück muss.

Telefonnummern werden ausgetauscht.

### 9. Verabschiedung

Die Verabschiedung findet ungefähr um 17:00 Uhr statt.

Es gibt einen Gruppen-Handklatscher.

Danach kommt ein schwarzer Fade.

Young Lean und die Gruppe gehen in unterschiedliche Richtungen.

### 10. Garten-Session

Es gibt eine Session mit einem gelb-schwarzen Ball.

Ein Spieler steht in der Mitte.

Die kleinste und größte Person werfen bzw. passen um die Person in der Mitte herum.

### 11. Essen

Es kommt der Text bzw. die Audioansage:

„Kinder, kommt essen.“

Die Mutter wird nicht gezeigt.

### 12. PS5 und spätere Szenen

Danach folgen weitere PS5- und spätere Szenen mit schwarzen Fades.

## Gameplay-Regel

Begehbare Abschnitte, die als interaktiv vorgesehen sind, bleiben spielbar und werden nicht automatisch zu Cutscenes.

## In-Game Start Menu

Wenn der Spieler während des Spiels Start drückt, erscheint ein graues Menü.

Das Menü enthält genau:

* Save
* Control Settings
* Return to the Menu

### Save

Save speichert den aktuellen Spielstand auf der SD-Karte.

Auch der ausgewählte Name und die Sprache werden gespeichert.

## Control Settings

Die festgelegte Steuerung ist:

**N64-artige Steuerung mit Joysticks**

Diese Steuerung ist die empfohlene Steuerung.

Eine alternative DS-Steuerung mit Steuerkreuz wird nicht verwendet.

## System Settings

Die System Settings enthalten genau:

* Bildschirm
* Audio
* Steuerung
* Sprache
* Datum
* Uhrzeit
* Systeminfo
* Auf Standardeinstellung zurücksetzen

Es gibt keine Server-Einstellungen.

## Free Open World

Der Spieler kann Peine frei erkunden.

### Aktivitäten

* durch Peine laufen
* mit der Bahn fahren
* mit dem Bus fahren
* zum Aldi laufen
* mit dem Bus zum Aldi fahren
* gemeinsam die Stadt erkunden

Die Stadt ist 24/7 aktiv.

Es gibt einen vollständigen Tagesablauf:

**Tag → Sonnenuntergang → Nacht → Sonnenaufgang → Tag**

Das Nachhausegehen als verpflichtende Aktivität ist entfernt.

Es gibt kein erzwungenes Nachhausegehen.

Der Spieler kann weiterhin frei in Peine unterwegs sein.

Es gibt keinen erzwungenen Story-Fortschritt innerhalb der Free Open World.

## Local Multiplayer

Der Multiplayer ist ausschließlich lokal.

Es gibt genau **3 Spieler**.

Die drei spielbaren Charaktere sind:

* Setzmann
* Sermijan
* Sefkan

### Charakterzuweisung

Die Spieler können nicht selbst auswählen, welchen Charakter sie spielen.

Das Spiel weist die drei Charaktere zufällig den drei Spielern zu.

Jeder der drei Spieler steuert einen der drei Charaktere.

### Gemeinsame Aktivitäten

Die drei Spieler können gemeinsam die vorgesehenen Free-Open-World-Aktivitäten ausführen:

* durch Peine laufen
* Bahn fahren
* Bus fahren
* zum Aldi laufen
* mit dem Bus zum Aldi fahren
* gemeinsam die Stadt erkunden

## Removed Content

Folgende Inhalte sind derzeit ausdrücklich nicht Bestandteil des Spiels:

* Online-Multiplayer
* Server
* Server-Einstellungen
* DS-Steuerung mit Steuerkreuz
* erzwungenes Nachhausegehen
* „Schweinchen in der Mitte“ als Multiplayer-/Free-Open-World-Modus

## Music and Audio

* Das Spiel verwendet das Young-Lean-Konzert als Intro.
* „Ginseng Strip 2002“ ist Teil der Story-Szene.
* In Fahrzeugen, Zügen und Bussen kann Musik verwendet werden.
* Zu Fuß gibt es Umgebungsgeräusche.
* Das In-Game-Startmenü ist grau und verwendet die festgelegte Menü-Musik in Endlosschleife.

## Persistence

Die folgenden Daten müssen dauerhaft gespeichert werden:

* Spielername
* Sprache
* Spielstand

Die Speicherung erfolgt auf der SD-Karte.

## Project Rule

Die oben genannten Festlegungen sind der aktuelle verbindliche Spielstand des Projekts.

Bei zukünftigen Änderungen dürfen bestehende Festlegungen nicht ohne ausdrückliche Änderung durch den Entwickler überschrieben werden.
