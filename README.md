# Peine PSP Game

## Current Game Specification

- **Platform:** PlayStation Portable (PSP)
- **Visual target:** Besser als Nintendo 64, angepasst an die PSP-Hardware
- **Story Mode**
- **Free Open World**
- **Local Multiplayer:** ausschließlich lokal, kein Online-Modus und keine Server
- **System Settings**

## Main Menu

1. Story Mode
2. Free Open World
3. Multiplayer
4. System Settings

## Intro

Das Spiel beginnt mit einem Young-Lean-Konzert. Die Musik läuft ungefähr 5–6 Sekunden. Danach wird das Bild langsam dunkler und die Musik blendet aus.

Anschließend wählt der Spieler:
- seinen Namen
- seine Sprache

Name und Sprache werden auf der SD-Karte gespeichert.

## Story Mode

1. Brücke: Der Spieler steuert Setzmann. Erinnerung an „Ginseng Strip 2002“.
2. Ein Mann mit Kapuze erscheint, summt „Ginseng Strip 2002“ und wird als Young Lean erkannt. Der Dialog ist auf Englisch.
3. Spielplatz: Sitzen, chillen, ein Lied singen und den nächsten Tag planen.
4. Zuhause: Betten/Matratzen, PS5 und Gespräch über den nächsten Tag. Der ältere Cousin schlägt Fußball um 2 Uhr nachts vor. Danach wird Fußball geschaut.
5. Schwarzer Fade, Schlafen, nächster Morgen.
6. Zweites Treffen an der Brücke; Setzmann wird gesteuert.
7. Aldi: spielbarer Abschnitt. Getränke und Center Shocks kaufen. Die Getränkedesigns sind eigenständig.
8. Zurück zum Spielplatz. Young Lean sagt, dass es wahrscheinlich das letzte Treffen ist, weil er zurück muss. Telefonnummern werden ausgetauscht.
9. Verabschiedung gegen 17:00 Uhr. Gruppen-Handklatscher, schwarzer Fade. Young Lean und die Gruppe gehen in unterschiedliche Richtungen.
10. Garten-„Session“ mit gelb-schwarzem Ball. Ein Spieler steht in der Mitte; die kleinste und größte Person werfen bzw. passen um die Person in der Mitte herum.
11. Essensruf als Text/Audio: „Kinder, kommt essen.“ Die Mutter wird nicht gezeigt.
12. PS5 und spätere Szenen mit schwarzen Fades.

### Gameplay-Regel

Begehbare Abschnitte, die als interaktiv vorgesehen sind, bleiben spielbar und werden nicht automatisch zu Cutscenes.

## Controls

Die festgelegte Steuerung ist eine **N64-artige Joystick-Steuerung**.

## In-Game Start Menu

Das Startmenü ist grau und enthält:

- Save
- Control Settings
- Return to the Menu

Der Spielstand wird auf der SD-Karte gespeichert.

## System Settings

Die System Settings enthalten genau:

- Bildschirm
- Audio
- Steuerung
- Sprache
- Datum
- Uhrzeit
- Systeminfo
- Auf Standardeinstellung zurücksetzen

Es gibt **keine Server-Einstellungen**.

## Free Open World

- Setzmann ist der spielbare Charakter.
- Sermijan und Sefkan begleiten ihn.
- Die Stadt Peine kann frei erkundet werden.
- Fortbewegung zu Fuß, mit dem Zug und mit dem Bus.
- Aldi kann zu Fuß oder mit dem Bus erreicht werden.
- Die Stadt bleibt 24/7 aktiv.
- Tagesablauf: Tag → Sonnenuntergang → Nacht → Sonnenaufgang → Tag.
- Keine verpflichtenden Dialoge.
- Kein erzwungener Story-Fortschritt.
- „Schweinchen in der Mitte“ / Session ist **nicht** Bestandteil von Free Open World oder Multiplayer.
- Musik in Fahrzeugen, Zügen und Bussen; zu Fuß gibt es Umgebungsgeräusche.

## Local Multiplayer

- Ausschließlich lokaler Multiplayer.
- Kein Online-Modus.
- Keine Server.
- Genau 3 Spieler.
- Charaktere: Setzmann, Sermijan und Sefkan.
- Die Charakterzuweisung erfolgt zufällig.
- Spieler können ihren Charakter nicht auswählen.
- Die drei Spieler können gemeinsam die dafür vorgesehenen Free-Open-World-Aktivitäten ausführen.

## Persistence

Diese README dient als zusammengefasster Projektstand. Die festgelegten Regeln, Menüs, Story-Abläufe, Steuerung, Einstellungen und Multiplayer-Bedingungen sollen beim weiteren Entwickeln erhalten bleiben.
